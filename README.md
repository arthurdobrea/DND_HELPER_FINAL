# 🐉 DnD Helper

Личный помощник мастера: **миры** (кампании) со своими закладками — страницы PDF-книг, заклинания, предметы, монстры (Open5e API) — с фильтрами и заметками.
Next.js 16 (фронт + бэк в одном процессе) · SQLite (Drizzle ORM) · react-pdf · Docker.

## Запуск

```bash
docker compose up -d --build     # первый запуск / после изменений кода
docker compose up -d             # обычный запуск
docker compose down              # выключить
```

Открыть http://localhost:3000, ключ по умолчанию — `changeme`.
Свой ключ: создай файл `.env` рядом с `docker-compose.yml`:

```
ACCESS_KEY=мой-секретный-ключ
```

Все данные лежат в `./data` (`app.db` + `pdfs/`) — бэкап = скопировать папку.
При обновлении схемы старая база сохраняется рядом (`app.db.backup-v0`).

## Разработка без Docker

```bash
npm install
npm run dev
```

Без `ACCESS_KEY` в env вход не требует ключа. Данные пишутся в `./data`.

## Возможности

| Раздел | Что умеет |
|---|---|
| 🐉 Миры | При открытии сайта — выбор мира («Продолжить» последний) или создание нового. Переименование, удаление |
| 🌍 Мир | Все закладки мира в одном месте: слева список (поиск, фильтр по типу), справа полные статы / страница книги + заметки. `j`/`k` — следующая/предыдущая, `/` — поиск |
| 🧙 Персонажи | Партия мира: карточки с хитами (быстрый урон/лечение), КД, инициативой, пассивной внимательностью, Сл заклинаний. Лист персонажа — 2 страницы A4 как стандартный лист 5e: все числа меняются кнопками −/+ (Shift — ×5), модификаторы/навыки/спасброски/Сл считаются сами, урон сначала снимает временные хиты. Автосохранение, печать и PDF |
| 🐲 Монстры | ~3200 монстров из Open5e (SRD и сторонние книги). Фильтры: CR от/до, тип, размер, среда обитания, хиты, КД, передвижение (летает/плавает/лазает/копает), чувства, мировоззрение, легендарные действия, колдует, иммунитет/сопротивление/уязвимость к урону, иммунитет к состояниям, минимальная характеристика, язык, телепатия, источник; поиск по имени или по тексту способностей; сортировка по CR/хитам/КД |
| ✨ Заклинания | ~2000 заклинаний: круг, класс, школа, время, концентрация, ритуал, спасбросок, тип урона, накладываемое состояние, источник. **Назначение**: лечение, воскрешение, урон, контроль, защита, снятие эффектов, призыв, перемещение, разведка, скрытность (определяется по тексту описания) |
| 🗡️ Предметы | ~2800 обычных и магических предметов: категория, редкость, цена от/до, вес, настройка, тип урона оружия, источник, сортировка по цене/редкости |
| 📚 Книги | Общая библиотека для всех миров. Загрузка PDF любого размера (потоком на диск), просмотр с подгрузкой по Range |
| 🔖 Закладки | Кнопка «🔖 В закладки мира» у монстра/заклинания/предмета, клавиша `B` в книге. Хранится копия записи — работает офлайн |

Каталоги монстров, заклинаний и предметов скачиваются из Open5e v2 **один раз** при первом открытии вкладки (~5–10 с)
и хранятся в SQLite — дальше фильтрация локальная и мгновенная, работает без интернета.
Кнопка «↻ Обновить из Open5e» внизу панели фильтров перекачивает каталог.
Фильтры живут в URL — удобный набор можно сохранить в закладки браузера.

У магических предметов в API нет цены: используется оценка по редкости из Xanathar's Guide (≈).

**Горячие клавиши в книге:** `←`/`→` листать · `B` новая закладка · `+`/`−` зум · `Home`/`End`.
Текущая страница хранится в URL (`/books/1?page=42`) — можно добавить в закладки браузера.

## Структура

```
src/
  proxy.ts                     проверка ключа (cookie dnd_key)
  lib/db/                      схема SQLite + подключение (таблицы и миграции — при старте)
  lib/world.ts                 текущий мир (cookie dnd_world), закладки мира
  lib/character.ts             модель листа персонажа и расчёты (модификаторы, навыки, Сл)
  lib/open5e.ts                клиент Open5e API (монстры, v1)
  lib/catalog/                 каталоги Open5e v2: загрузка в SQLite, нормализация, фильтры
    spells.ts                  фильтр заклинаний + определение «назначения» по тексту
    items.ts                   фильтр предметов + оценка цены по редкости
  app/actions.ts               server actions: избранное, закладки, книги, логин
  app/api/books/upload         загрузка PDF (PUT, тело = файл)
  app/api/books/[id]/file      отдача PDF с Range
  app/worlds, world            выбор мира, страница мира
  app/characters               партия и лист персонажа (components/character/)
  app/monsters, spells, items, books   каталоги и книги
  components/world/            список закладок, шапка закладки, страница книги в мире
  components/PdfPane.tsx       просмотр страницы PDF (используется в книге и в мире)
  components/filters/          автоприменяемая форма фильтров и поля
  components/BookViewer.tsx    PDF-вьюер + панель закладок
```
