# 🐉 DnD Helper

Личный помощник мастера: **миры** (кампании) со своими закладками — страницы PDF-книг, заклинания, предметы, монстры (Open5e API) — с фильтрами и заметками.
Next.js 16 (фронт + бэк в одном процессе) · SQLite (Drizzle ORM) · react-pdf · Docker.

## Запуск

```bash
docker compose up -d --build     # первый запуск / после изменений кода
docker compose up -d             # обычный запуск
docker compose down              # выключить
```

Открыть http://localhost:3000, ключ по умолчанию — `changeme`.
Свой ключ: создай файл `.env` рядом с `docker-compose.yml`:

```
ACCESS_KEY=мой-секретный-ключ
```

Все данные лежат в `./data` (`app.db` + `pdfs/`) — бэкап = скопировать папку.
При обновлении схемы старая база сохраняется рядом (`app.db.backup-v0`).

## Автоперевод на русский (бесплатно, офлайн)

Описания монстров, заклинаний и предметов приходят из Open5e на английском. Приложение переводит их на русский
через **LibreTranslate** — бесплатный переводчик, который `docker compose` поднимает рядом с приложением
(контейнер `libretranslate`, без ключей и без внешних сервисов). Открыл карточку — английский текст сам сменяется
русским (сверху «Перевожу на русский…»).

- **Первый запуск** скачивает языковую модель en→ru (несколько минут, один раз; хранится в томе
  `libretranslate_models`), дальше работает без интернета. Образ переводчика ~1 ГБ.
- **Качество.** Это машинный перевод, не уровень нейросети: смысл передаётся, но встречаются корявости. Чтобы их было
  меньше, игровые термины (спасбросок, хиты, Класс Доспеха, помеха/преимущество, виды урона, «досягаемость», ход…)
  и типовые фразы переводятся по глоссарию (`src/lib/translate/glossary.ts`), а короткие поля — урон, состояния,
  чувства, языки, броня, названия способностей — по словарю (`dictionary.ts`). Названия существ, заклинаний и
  предметов не переводятся (остаются как в книгах). Подправить глоссарий и словари можно прямо в этих файлах.
- **Где.** Каталоги, страница мира (закладки), магазин (полка и карточки) и **экспорт в PDF** — всё на русском.
  Переключатель **RU / EN** над карточкой возвращает оригинал; у PDF язык берётся из него же.
- **Кэш.** Каждый уникальный текст переводится **один раз** и хранится в `app.db` (таблица `translations_ru`):
  повторно он берётся из базы мгновенно.
- **Скорость.** Переводчик работает на процессоре: карточка монстра — секунды, большой магазин — до минуты.
- **Если сервис не запущен**, страницы показывают текст на английском и подсказку; через минуту приложение
  пробует снова. Выключить перевод совсем: `TRANSLATE_DISABLED=1`.
- **Без Docker** (`npm run dev`): `docker compose up -d libretranslate` — порт 5000 уже проброшен, приложение
  ищет сервис на `http://localhost:5000` (можно поменять в `LIBRETRANSLATE_URL`).

## Разработка без Docker

```bash
npm install
npm run dev
```

Без `ACCESS_KEY` в env вход не требует ключа. Данные пишутся в `./data`.

## Возможности

| Раздел | Что умеет |
|---|---|
| 🐉 Миры | При открытии сайта — выбор мира («Продолжить» последний) или создание нового. Переименование, удаление |
| 🌍 Мир | Все закладки мира в одном месте. Слева — категории с крупными значками: **💀 Монстры / 🧍 NPC / 💎 Артефакты / 📍 Локации / 🗺️ Карты** (+ «Без категории»). **Свои категории**: «＋ Своя категория» под списком (или «Новая категория…» в меню «⋯») — название, цвет из палитры и значок из набора; правка — ✏️ у категории, при удалении закладки переходят в «Без категории». Любую закладку — страницу книги, заклинание, предмет, монстра — можно положить в любую категорию: **перетащить на заголовок категории**, кнопкой **«⋯»** у закладки или значками категорий в шапке открытой закладки. По умолчанию монстры попадают в «Монстры», предметы — в «Артефакты», страницы и заклинания — в «Без категории» (страницу можно сразу отнести к категории при добавлении клавишей `B`). Категории сворачиваются; поиск, фильтр по типу записи; справа полные статы / страница книги + заметки. `j`/`k` — следующая/предыдущая, `/` — поиск |
| 🧙 Персонажи | Партия мира: карточки с хитами (быстрый урон/лечение), КД, инициативой, пассивной внимательностью, Сл заклинаний. Лист персонажа — 2 страницы A4 как стандартный лист 5e: все числа меняются кнопками −/+ (Shift — ×5), модификаторы/навыки/спасброски/Сл считаются сами, урон сначала снимает временные хиты. Автосохранение, печать и PDF |
| 🐲 Монстры | ~3200 монстров из Open5e (SRD и сторонние книги). Фильтры: CR от/до, тип, размер, среда обитания, хиты, КД, передвижение (летает/плавает/лазает/копает), чувства, мировоззрение, легендарные действия, колдует, иммунитет/сопротивление/уязвимость к урону, иммунитет к состояниям, минимальная характеристика, язык, телепатия, источник; поиск по имени или по тексту способностей; сортировка по CR/хитам/КД |
| ✨ Заклинания | ~2000 заклинаний: круг, класс, школа, время, концентрация, ритуал, спасбросок, тип урона, накладываемое состояние, источник. **Назначение**: лечение, воскрешение, урон, контроль, защита, снятие эффектов, призыв, перемещение, разведка, скрытность (определяется по тексту описания) |
| 📖 Книги (PDF) | Закладки страниц и вьюер. Названия заклинаний в `[скобках]` на **открываемой странице** (например «волшебная рука [mage hand]») подсвечиваются; при наведении появляется окно с описанием на русском, клик закрепляет окно, там же кнопка «В закладки мира». Сканируется только видимая страница, не весь файл |
| ⚔️ Столкновения | Генератор столкновений по правилам DMG: берёт уровни героев мира (можно снять галочки или добавить героев вручную), сложность (лёгкий / средний / тяжёлый / смертельный), режим **👑 Босс-файт** (один сильный враг, чаще легендарный, + приспешники) и тип врагов (нежить, бандиты, культисты, звери, драконы, исчадия и др., можно несколько) и источник. CR главного врага привязан к среднему уровню героев: лёгкий — на 2 ниже, средний — равный, тяжёлый и смертельный — на 2 выше; босс всегда строго выше среднего уровня. Врагов не меньше, чем героев (до двух на героя), 2–4 разных вида. Показывает состав, опыт и сложность, статблоки, кнопка «В закладки мира»; «Сгенерировать заново» даёт новый вариант |
| 🗡️ Предметы | ~2800 обычных и магических предметов: категория, редкость, цена от/до, вес, настройка, тип урона оружия, источник, сортировка по цене/редкости |
| 🏺 Магазин | Магазин артефактов мира: вещи добавляются из общего каталога предметов (поиск и фильтры по типу, категории, редкости, цене; «＋» у вещи или «добавить все найденные»). У каждой вещи своя цена в золотых и остаток на складе (или ∞) с кнопками −/+; нулевой остаток помечается «нет в наличии». Полная карточка вещи справа, итоговая стоимость склада в шапке Кнопка **«📄 Экспорт в PDF»** скачивает прайс-лист: вещи списком (название, цена, описание, редкость, остаток; по категориям, A4, с нумерацией страниц). Вещи «нет в наличии» в PDF не попадают |
| 📚 Книги | Общая библиотека для всех миров. Загрузка PDF любого размера (потоком на диск), просмотр с подгрузкой по Range |
| 🔖 Закладки | Кнопка «🔖 В закладки мира» у монстра/заклинания/предмета, клавиша `B` в книге. Хранится копия записи — работает офлайн |

Каталоги монстров, заклинаний и предметов скачиваются из Open5e v2 **один раз** при первом открытии вкладки (~5–10 с)
и хранятся в SQLite — дальше фильтрация локальная и мгновенная, работает без интернета.
Кнопка «↻ Обновить из Open5e» внизу панели фильтров перекачивает каталог.
Фильтры живут в URL — удобный набор можно сохранить в закладки браузера.

У магических предметов в API нет цены: используется оценка по редкости из Xanathar's Guide (≈).

**Горячие клавиши в книге:** `←`/`→` листать · `B` новая закладка · `+`/`−` зум · `Home`/`End`.
Текущая страница хранится в URL (`/books/1?page=42`) — можно добавить в закладки браузера.

## Структура

```
src/
  proxy.ts                     проверка ключа (cookie dnd_key)
  lib/db/                      схема SQLite + подключение (таблицы и миграции — при старте)
  lib/world.ts                 текущий мир (cookie dnd_world), закладки мира
  lib/groups.ts                категории закладок: встроенные, палитра и набор значков (свои — таблица world_categories)
  components/CategoryIcon.tsx  значки категорий (SVG)
  lib/character.ts             модель листа персонажа и расчёты (модификаторы, навыки, Сл)
  lib/open5e.ts                клиент Open5e API (монстры, v1)
  lib/translate/               автоперевод: LibreTranslate (engine.ts), глоссарий (glossary.ts), словари (dictionary.ts), кэш в SQLite (store.ts)
  lib/catalog/                 каталоги Open5e v2: загрузка в SQLite, нормализация, фильтры
    spells.ts                  фильтр заклинаний + определение «назначения» по тексту
    items.ts                   фильтр предметов + оценка цены по редкости
  app/actions.ts               server actions: избранное, закладки, книги, логин
  app/api/books/upload         загрузка PDF (PUT, тело = файл)
  app/api/books/[id]/file      отдача PDF с Range
  app/worlds, world            выбор мира, страница мира
  app/characters               партия и лист персонажа (components/character/)
  app/monsters, spells, items, books   каталоги и книги
  app/shop                     магазин артефактов (components/shop/)
  app/api/shop/pdf             экспорт магазина в PDF (lib/shop-pdf.ts; шрифты DejaVu — public/fonts)
  components/world/            список закладок, шапка закладки, страница книги в мире
  components/PdfPane.tsx       просмотр страницы PDF (используется в книге и в мире)
  components/filters/          автоприменяемая форма фильтров и поля
  components/BookViewer.tsx    PDF-вьюер + панель закладок
```
